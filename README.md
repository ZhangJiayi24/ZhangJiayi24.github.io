# Jiayi Zhang — Academic Homepage

Source for [zhangjiayi24.github.io](https://zhangjiayi24.github.io/).

This is a build-free static site. The page lives in `index.html`, with styles
in `stylesheet.css` and local assets under `assets/` and `images/`.

For a local preview:

```bash
python3 -m http.server 8000
```
